# eFaktura Viewer 1.2.2

Oprava ovládania klávesnicou po hromadnom premenovaní faktúr.

- Šípky doľava a doprava fungujú ihneď po premenovaní, bez predchádzajúceho kliknutia myšou.
- Po zatvorení dialógu a obnovení náhľadu aplikácia obnoví stratený fokus klávesnice. Aktívnemu inému oknu ho nepreberá.
- Regresný test overuje premenovanie dvoch faktúr a následné listovanie oboma smermi zo skutočne fokusovaného ovládacieho prvku.
